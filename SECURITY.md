# Security Policy

## Supported versions

| Version          | Supported |
|------------------|-----------|
| 1.x              | Yes       |
| Earlier versions | No        |

## Reporting a vulnerability

Please report security vulnerabilities privately through the repository's GitHub Security Advisory feature. Do not disclose the issue publicly until a fix is available.

Include the affected package version, Laravel and Nova versions, reproduction steps, expected behavior, and the security impact. Reports will be reviewed as soon as practical, and coordinated disclosure will be arranged when the issue is confirmed.

Never include real Nova credentials, application secrets, tenant data, or production cookies in a report.
